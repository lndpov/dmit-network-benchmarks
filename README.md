## DMIT 速度测试：三大机房实测数据

### 洛杉矶 CN2 GIA（LAX.Pro）

洛杉矶是 DMIT 主力机房，产品线最全，也是做跨境梯子的人买得最多的。

去程：电信走 AS4809（GIA），联通直连 AS4837，移动从香港出境（AS58453）。回程：三网统一走 CN2 GIA 回来，这个是重点——不管哪家运营商，回国都走高端线路。

实测情况：

- 上海电信延迟大约在 130ms 上下，已经接近物理极限了（太平洋光速单程理论值约 120ms）
- 全国平均在 150–180ms，绝大部分城市都绿
- 晚高峰（北京时间 21:00–23:00）丢包率几乎是 0，这一点比延迟本身更值钱
- 带宽跑起来，下载方向能跑到配额上限，上传（回国方向）在高峰期有小幅波动，但整体稳

简单说：洛杉矶 CN2 GIA 属于跨太平洋线路里表现最稳的那档。晚高峰不塌，丢包极少，用来搭梯子或者跑需要稳定连接的服务都可以。

### 洛杉矶 Eyeball（LAX.EB）—— CMIN2 回程

EB 系列比 Pro 便宜一档，回程三网走 CMIN2（电信 / 联通走 AS9929，移动走 AS58807）。

延迟比 Pro 稍高，大概在 160–200ms 区间，但比普通 BGP 线路还是好不少。联通和移动用户来用这个性价比更合适，因为 9929 和 CMIN2 对这两家走的路是专门优化过的。

流量超限后不关机，而是限速到 4Mbps，这个设定对长期挂服务的人很友好。

### 香港 CN2 GIA（HKG.Pro）

香港是国内延迟最低的选择。地理位置在那，物理距离决定上限。

实测：国内主要城市延迟普遍在 20–50ms。电信双向 CN2 GIA，联通和移动直连。晚高峰速度基本跑满带宽上限，丢包几乎没有。

缺点也明显：价格贵，而且库存经常是缺货状态。想买香港 Pro，有时候要蹲。

### 日本东京 CN2 GIA（TYO.Pro）

日本机房的路由：电信走 CN2 GIA，联通走 AS9929，移动走 CMI。

延迟数字：国内主要城市 Ping 基本在 50–80ms，对于日本机房来说是正常水平。电信用户体验最好，联通也行，移动用户因为要绕一圈，延迟稍微高一点但整体仍在可接受范围。丢包测下来基本是零。

TYO.AS3.EB（日本 Eyeball 系列）已于近期下架，目前东京只有 Pro 和 T1 两条线。

### 圣何塞（SJC.T1）—— 纯国际线路

这个机房没有中国优化，主要面向国际业务或者用来做落地的场景。带宽大，价格相对实惠，标配 20Gbps DDoS 防护。如果你的用户主要在北美或者东南亚，可以考虑；但如果主要连国内，跳过。

## 怎么做 DMIT 速度测试：自己验证的四步流程

买 VPS 之前最好先用官方测试 IP 跑一下延迟，别光看别人的数据。

1. **用 ping 命令测延迟**：各机房官方测试 IP 如下——洛杉矶 CN2 GIA：`154.17.2.2`；洛杉矶 EB：`154.17.226.2`；香港：`103.135.248.1`；东京：`45.88.192.1`。直接 `ping 154.17.2.2 -n 20`（Windows）或 `ping -c 20 154.17.2.2`（Linux/Mac）。
2. **跑路由追踪**：Windows 用 `tracert`，Linux/Mac 用 `traceroute` 或 `mtr`。看路由里有没有出现 `59.43` 开头的节点——这是 CN2 GIA 的特征 IP 段，有这个就说明真的走了 GIA 线路，没有的话商家标称可能有出入。
3. **用 Speedtest 测带宽**：服务器上装好系统后，`apt install speedtest-cli` 然后跑一下，选国内节点（上海、北京都行），看下载 / 上传速度。重点是在晚上 8–10 点这个时段跑，白天数据参考价值低。
4. **对比三网**：电信、联通、移动用户体验可能差别挺大，条件允许的话三个运营商都测一下。

## FAQ

**Q：怎么判断 DMIT 的 CN2 GIA 是真 GIA 还是假 GIA？**

A：跑路由追踪，看经过的节点里有没有 IP 以 `59.43` 开头的跳数。这是中国电信 CN2 GIA 骨干网的特征网段，出现就是真的，没出现说明走的是普通 CN2 或者直接 163 骨干网，价格和性能都不一样。

**Q：洛杉矶 Pro 和 Eyeball 到底选哪个？**

A：主要看你是什么运营商。电信用户，Pro 的回程 CN2 GIA 对你更友好，延迟和稳定性都有优势。联通和移动用户，EB 系列的 9929 和 CMIN2 对这两家运营商的优化其实也不差，加上 EB 系列可以用那个 8 折循环码，综合下来性价比更高。

**Q：香港 VPS 延迟这么低，为什么不都选香港？**

A：香港 Pro 是最快的，但价格也最贵，而且库存紧张，常常缺货。加上 IP 被封了国内方向没有防护，遇到攻击会黑洞。如果你的场景对延迟没那么极致，洛杉矶 CN2 GIA 是更稳定的长期选择。

**Q：T1 系列能不能用来访问国内？**

A：T1 是纯国际线路，没有专门的中国大陆优化，电信联通走 NTT 等国际运营商，延迟和稳定性不如 Pro / EB 系列，不推荐用来做国内访问需求的场景。T1 适合国际建站、东南亚业务、或者搭配中转自用。

**Q：DMIT VPS 可以搭 Shadowsocks / V2Ray / Trojan 这类服务吗？**

A：VPS 本身是标准 KVM Linux 虚拟机，技术上支持跑任何合法服务。具体使用场景用户自行负责，DMIT 官方不做限制也不做背书。
